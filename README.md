# 🇸🇦 قالب موقع إلكتروني لشركات تنظيف المنازل في السعودية
### Saudi Home Cleaning Company Website Template (Reusable & Netlify-Ready)

قالب موقع إلكتروني متكامل، عصري، فائق الجودة وسريع، مبني خصيصاً لمصممي ومطوري المواقع (Freelancers) لتقديمه وإعادة استخدامه بسرعة فائقة مع مختلف شركات ومؤسسات تنظيف المنازل في المملكة العربية السعودية.

---

## 🌟 مميزات القالب (Key Features)

1. **إعداد مركزي وسريع (100% Config-Driven)**:
   - كافة بيانات الشركة، الأسعار، الخدمات، النصوص، أرقام التواصل، والمدن موجودة في ملف إعدادات واحد (`src/businessConfig.ts` و `businessConfig.js`).
   - لا حاجة لكتابة كود جديد أو لمس مكونات React عند استلام عميل جديد!

2. **لغة وتصميم سعودي أصيل**:
   - واجهة كاملة من اليمين إلى اليسار (RTL) مع خطوط عربية فاخرة (`Cairo` و `IBM Plex Sans Arabic`).
   - ألوان فندقية راقية: الأخضر الزيتي العميق (Deep Teal `#0D5C53`) مع لمسات الأخضر النضر (Soft Emerald `#10B981`) والرمادي الفاتح المريح للعين.

3. **تكامل فوري مع واتساب (WhatsApp Direct Booking)**:
   - جميع أزرار الحجز تقوم بإنشاء رابط واتساب مباشر برسالة عربية منسقة مسبقاً تحمل اسم الخدمة أو الباقة والسعر التقديري.

4. **متجاوب 100% مع الهواتف الذكية (Mobile-First)**:
   - قائمة تنقل منسدلة خفيفة، وأزرار لمس واسعة ومريحة لسهولة الحجز الفوري أثناء تصفح الجوال.

5. **جاهز للنشر على Netlify بضغطة زر**:
   - يحتوي المشروع على إعدادات `netlify.toml` الجاهزة، مع مخرجات بناء نقية في مجلد `dist/`.

## 🛠️ كيفية تخصيص الموقع لعميل جديد (How to Customize for a New Client)

لتسليم موقع احترافي لعميل جديد خلال أقل من 10 دقائق:

### الخطوة 1: تعديل ملف الإعدادات `src/businessConfig.ts`
افتح الملف وعدّل القيم التالية بمعلومات العميل الحقيقية:
- **اسم الشركة**: `companyName: "شركة لمعان الرياض للتنظيف"`
- **رقم الواتساب**: `whatsappNumber: "9665XXXXXXXX"` *(أرقام فقط بدون + أو 00)*
- **رقم الهاتف**: `phoneDisplay: "050 XXX XXXX"`
- **المدينة**: `city: "الرياض"` أو `"جدة"` أو `"الدمام"`
- **الأحياء المشمولة**: عدّل مصفوفة `neighborhoods` بحسب الأحياء التي يغطيها العميل فعلياً.
- **الأسعار**: عدّل أو احذف الأسعار في `services` و `pricingPackages`.
- **رابط خرائط جوجل**: ضع رابط موقع فرع العميل الفعلي، واضبط `isVerifiedLocation: true`.

### الخطوة 2: استبدال الصور
ضع صور العميل المعتمدة (صور تنظيف الكنب، الشقق، الفلل) في مجلد `src/assets/images/` أو استبدل روابط الصور في ملف `src/businessConfig.ts`.

## 📦 البناء والنشر على Netlify (Deployment to Netlify)

### الطريقة الأولى: السحب والإفلات (Drag & Drop)
1. شغّل أمر البناء للإنتاج:
   ```bash
   npm run build
   ```
2. سيتم إنشاء مجلد باسم `dist/`.
3. توجّه إلى لوحة تحكم [Netlify Drop](https://app.netlify.com/drop) واسحب مجلد `dist` فقط!
4. سيصبح موقعك متاحاً على الإنترنت برابط فوري مجاني أو يمكنك ربط دومين العميل الخاص (`.sa` أو `.com`).

### الطريقة الثانية: الربط مع مستودع Git (GitHub / GitLab)
1. ارفع المشروع إلى مستودع GitHub.
2. في Netlify، اختر **Add new site > Import an existing project**.
3. سيتعرّف Netlify تلقائياً على ملف `netlify.toml`:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
4. اضغط **Deploy Site**.
